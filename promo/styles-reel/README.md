## Retime for a new take
1. Replace `assets/maria.mp4`, then `npx hyperframes transcribe assets/maria.mp4`.
2. Copy the name start times into `STARTS`, and set `END`, `CTA`, `TOTAL` and the `CAPS` times in `make_reel.py`.
3. Phone clips in `assets/clips/` and blurred backgrounds in `assets/bgblur/` should cover each name's slot; the grid clips are in `assets/grid/`.
4. Layout: `PH_*` (phone box), `SCALE` (circle size), `PIP` / `CTA_POS` (circle centres), `FACE_X/FACE_Y` (face in the source).
5. `python3 make_reel.py`, set the scene duration in `scenes.json` to `TOTAL`, `python3 ../../tools/build_index.py .`, then `npx hyperframes check && npx hyperframes render -o promo.mp4`.

## Sound
- **Voice:** from `assets/maria.mp4` (volume 1.25).
- **Music bed:** `assets/bgm/track.mp3`, 28 s, generated offline with HyperFrames' local MusicGen fallback (`facebook/musicgen-small`). Prompt: "upbeat modern creator reel instrumental, punchy hip hop drums, bright plucky synths, warm bass, confident and fun, 115 bpm, no vocals". It sits under the voice at 0.175 and fades out over the last 1.2 s. Note: the MusicGen model weights are licensed CC-BY-NC 4.0, so for paid or ad use swap in a licensed track (or use Instagram's audio library when posting).
- **Effects:** HyperFrames' bundled Pixabay-licensed SFX (`assets/sfx/CREDITS.md`). Each style landing in the phone gets one hit, rotating whoosh → pop → whoosh-b → pop-b (the -b takes are pitch-shifted copies). There's also a whoosh as the phone leaves, a pop on "repo.", and a bass impact on the grid reveal. Every hit's peak lands one frame after its picture.
- **Measured** (not listened to): −16.2 LUFS integrated, true peak −2.9 dBTP, no clipping. Cue times and levels live in `make_reel.py` (`cues`, `MUSIC_VOL`, `SFX_VOL`, `VOICE_VOL`).
